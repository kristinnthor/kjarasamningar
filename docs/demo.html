Sýnidæmi

Þessi síða sækir gögnin beint af API-inu í vafranum þínum — ekkert er innbyggt í hana. Ef myndin birtist er API-ið í lagi.

    Sæki gögn af API-inu …
    Vísitalan leggur saman þær hækkanir sem fundust í samningum og er hér sýnd fyrir félög sem bera merkinguna samfelld, frá þeim degi sem samfelld_fra segir. Hún er ekki launavísitala Hagstofunnar.

    Kóðinn á bak við myndina

    const grunnur = "https://kjarasamningar.kristinn.eu/api/v1";

// 1. Sækja félagalistann og velja þau sem bera samfellda röð
const { felog } = await fetch(`${grunnur}/felog.json`).then(r => r.json());
// Samfella er mæld aftur á bak frá nýjustu mælingu; samfelld_fra segir frá hvenær
const valin = felog.filter(f => f.heilleiki === "samfelld"
                                && f.samfelld_fra <= "2015-01-01");

// 2. Sækja tímaröð hvers félags
const rod = await fetch(`${grunnur}/felog/${valin[0].audkenni}.json`)
  .then(r => r.json());

// 3. Nota hana
rod.haekkanir
  .filter(h => h.innan_samfellu)
  .forEach(h => console.log(h.dagsetning, h.prosenta, h.visitala_samfella));
